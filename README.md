# CSE438 Applied Data Science for Practitioners

Coursework and the group project from **CSE438 Applied Data Science for Practitioners** at BRAC University (2022). This is a fork of the group repository.

## Group project: skin cancer diagnosis with deep CNNs

[`Project and Report/`](Project%20and%20Report/) classifies dermatoscopic images from the [HAM10000](https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000) dataset into seven skin-lesion types, using deep convolutional neural networks in TensorFlow and Keras. It includes the notebook, the written report (PDF) and the slides. The notebook reports test accuracy of about 97–98%.

Group: Md. Farhadul Islam, Fardin Bin Rahman, Sarah Zabeen and Md. Azharul Islam. [Video walkthrough](https://youtu.be/Ry1glGGqEBE)

## Lab notebooks

| Notebook | Content |
|---|---|
| `Classification Algorithms.ipynb` | Several scikit-learn classifiers compared on the same dataset, with classification reports |
